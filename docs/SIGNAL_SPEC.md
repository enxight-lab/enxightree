# 시그널 정의서 (SIGNAL_SPEC) — pulse 온도차·시그널의 단일 진실원천(SSoT)

> 목적: 시그널 수치·임계·영역을 **추측 상수가 아니라 데이터에서 자동 도출되는 규칙**으로 못박는다.
> 한 번 정의하면 이력이 쌓일수록 코드 변경 0으로 신뢰도가 오른다(롤링 재캘리브레이션).
> 이 문서가 정의의 SSoT — `build_pulse.py`(산출)와 `public/pulse/index.html`(표시)이 양쪽에서 이 계약을 따른다.

작성 2026-06-16 · 상태: **초안(확정 대기)** · 근거: 실이력 분포 실측(`analyze_pulse_dist.py`)

---

## 0. 원칙

1. **경험적 백분위** — 정규분포를 가정하지 않는다. "오늘 값이 그 지역 과거 N일 분포에서 상위 몇 %인가"로만 판단. 금융 수익률의 fat-tail·뉴스 카운트의 비대칭과 무관하게 입증 가능(과거 관측을 세기만 하면 검산됨).
2. **지역별 독립 정규화** — 각 지역은 자기 과거 분포로만 평가(미국 σ와 신흥국 σ를 섞지 않음).
3. **롤링** — 분포는 직전 N일 창에서 매 집계 시 갱신. 정의(이 문서)는 고정, 숫자는 데이터가 정함.
4. **잠정 정직성** — 표본이 부족하면 신호를 단정하지 않고 "잠정"으로 표기하거나 보류한다.

## 1. 입력 (이미 수집 중)

| 축 | 원자료 | 출처 |
|---|---|---|
| 가격 | 일간 수익률 `chg`(%) = (종가−전일)/전일×100 | Yahoo (`fetch_prices`) |
| 뉴스 | 오늘 기사수 `news` = GDELT 7지역×5테마 합 | GDELT (`fetch_news`) |

---

## 2. 정규화 — 경험적 백분위

각 지역 `r`, 직전 `N`영업일 분포에서 오늘 값의 백분위를 구한다.

```
pct(x | 과거분포) = (과거 N일 중 x 보다 작은 관측 수) / (과거 N일 관측 수) × 100

가격 백분위  P_price[r] = pct( |chg_today[r]|  | 과거 N일 |chg[r]| 분포 )
뉴스 백분위  P_news[r]  = pct(  news_today[r]  | 과거 N일 news[r] 분포 )
```

- 가격은 **절대값** `|chg|`의 백분위(움직임 크기). 방향(상승/하락)은 `chg`의 부호로 별도 보존 → 표시에서 ▲▼.
- 뉴스는 **GDELT timelinevol 60일 시계열**의 백분위 — pulse KV 이력 불필요(원천 과거 직접 조달). 마지막 점(당일)은 부분집계·최신 인덱싱 편향이라 **전일(vals[-2])을 today** 로(가격 전일종가 원칙과 시점 일관), 같은 시계열 앞 점들이 분포 → 척도 자동 정합. GDELT 실패 시 pulse 이력 폴백.
- 참고용으로 z-score(`(x−μ)/σ`)도 동봉 가능하나 **판단 기준은 백분위**. z는 "몇 σ" 직관 표시용.

## 3. 파라미터 (확정 대상 — 근거 포함)

| 기호 | 값(권장) | 의미 | 근거 |
|---|---|---|---|
| `N` | **60영업일** | 롤링 창 | 약 3개월 = 변동성 레짐 반영 + 최신성 균형. 너무 길면 옛 레짐 혼입, 짧으면 백분위 불안정 |
| `θ` | **85** (상위 15%) | 유의 임계 백분위 | 정규의 1σ(84.1%)에 상응 — 직관적. 7지역×주5일=35관측/주 중 상위 15%면 주당 ~5건 유의 신호(과다·과소 아님) |
| `M_prov` | **20** | 잠정 최소 표본 | 백분위 해상도 ~5%. 미만이면 "잠정" 라벨 |
| `M_min` | **10** | 신호 표시 최소 표본 | 미만이면 시그널 비표시(데이터 부족 고지). 현재 이력 5일 → 당분간 여기 해당 |

---

## 4. 영역 정의 (4분면)

`유의_가격 = P_price ≥ θ` , `유의_뉴스 = P_news ≥ θ` 로 분류:

| 영역 | 뉴스 | 가격 | 의미 |
|---|---|---|---|
| **압력 축적** | 유의 | 비유의 | 뉴스 폭증인데 가격 정체 — 변동성 누적 |
| **조용한 이동** | 비유의 | 유의 | 뉴스 평이한데 가격 급변 — 수급 선행 |
| **추세 확인** | 유의 | 유의 | 뉴스가 가격 움직임을 뒷받침 |
| **무풍** | 비유의 | 비유의 | 평상 |

**강도(연속)** = `√(P_news² + P_price²) / √2` (0~100). 영역 내 순위·점 농도·브리핑 우선순위에 사용 — 경계 이진성 완화.

## 5. 잠정·fallback 정책

```
유효표본 n[r] = min(가격 관측 수, 뉴스 관측 수)  (지역별)

n ≥ M_prov(20)  → 정상 신호
M_min ≤ n < 20  → "잠정" 라벨 부착(백분위는 산출하되 신뢰주의 표기)
n < M_min(10)   → 시그널 비표시: "데이터 누적 중(n일/M_min일)" 고지
```

- fallback 으로 옛 절대임계(1.8배·0.5%)는 **쓰지 않는다** — 그것이 바로 폐기 대상. 부족하면 정직하게 "누적 중"을 보여준다.
- 가격축은 pulse 이력과 무관하게 **다중 소스 ladder 로 과거 N일 일봉을 즉시 확보**(실행 환경 무관, 2026-06-16 핑 검증):
  1. **네이버 해외지수** `api.stock.naver.com/index/{sym}/price?pageSize=N` — 미(.INX)·유(.STOXX50E)·중(.SSEC)·일(.N225)·브(.BVSP). 국내 IP 경유. 한국은 siseJson(KOSPI).
  2. **TwelveData ETF 프록시** — 7지역 전부(미 SPY·유 VGK·중 FXI·일 EWJ·한 EWY·브 EWZ·신흥 EEM). 무료등급. 네이버 미지원(신흥국)·실패 지역 보강.
  3. **Yahoo** — 최종.
  per-source fail-soft: 한 소스가 막혀도 지역별로 메워 수집 전멸 방지. → **가격 백분위는 조기 신뢰**, 뉴스축만 pulse 이력 누적을 기다린다.
  ※ ETF·유로스톡스50 은 원지수(STOXX600)와 추적오차가 있으나 **일간 변동률 백분위·방향엔 사실상 동일** → 시그널 용도 충분.

## 6. 데이터 계약 (`pulse.json` 확장)

`build_pulse.py`가 산출에 다음 블록을 추가, 프론트는 표시만(임계 재계산 금지 — 현재 백엔드·프론트 중복 제거):

```jsonc
"signal": {
  "spec_version": 1,
  "window": 60,          // N
  "theta": 85,           // θ
  "regions": {
    "us": {
      "p_news": 92.0,    // 뉴스 백분위
      "p_price": 40.0,   // 가격 백분위
      "chg": 0.12,       // 방향용
      "strength": 71.4,  // 강도
      "zone": "pressure",// pressure|quiet|trend|calm (두 축 모두 신뢰 시만)
      "n_price": 58, "n_news": 58,   // 축별 유효표본
      "price_provisional": false,
      "news_provisional": false,
      "price_src": "naver",          // naver|twelvedata|yahoo
      "news_src": "gdelt",           // gdelt|pulse_hist
      "z_price": 0.2                 // 참고용(표시 보조)
    }
  }
}
```

## 7. 자동화 (한 번 정의 → 영구 자동)

- `build_pulse.py`가 매 집계 시 직전 `N`일 이력을 읽어 백분위·영역을 재계산 → 별도 캘리브레이션 작업 불필요.
- 이력 5일 → 60일로 늘어도 **코드·이 문서 변경 0**. `n`이 임계를 넘는 순간 자동으로 "잠정" 해제.
- 파라미터(`N·θ·M`) 변경 시 **이 문서만 고치고** 코드는 상수 1곳을 참조.
